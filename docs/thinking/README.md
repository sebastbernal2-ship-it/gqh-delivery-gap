# Thinking

The process, not the conclusion. Post here as you go, not after.

What belongs here:

- back and forth between people, disagreements, the argument that changed someone's mind
- a line of reasoning that got revised, or abandoned, and why
- notes from reading a paper, a lecture, a dataset, a failure
- "here is how I am thinking about this today and I expect it to be wrong tomorrow"

## The only convention

One file per person per day per topic, named `YYYY-MM-DD-<github-handle>-<topic>.md`. Append to
it during the day. Do not tidy it later, do not rewrite it once someone has read it.

Why the date and the handle: the record of how the thinking moved is worth more than a tidy
document, and it is what makes the final write-up believable.

Nothing in this folder is a claim. When something here becomes a claim, it is promoted:
a file in `docs/theses/<id>.md` plus one line in the ledger. The thinking file stays where it is.

Do not put secrets, credentials, or personal data here. This repo is public.
