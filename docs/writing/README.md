# Writing

Everything about what we hand in, and how we write it.

- The note itself: one file per section, so two people never edit the same file.
- A style file, owned by whoever is setting the voice, so the note reads as one document rather than
  four. Put the rules there, not in chat.
- Anything the judges read: the note, the repo README, the abstract.

## Conventions

- One file per section, named for the section.
- Numbers come from `results/`. Never type a number into prose that you cannot point at a file for.
- Short sentences. Plain words. No filler.
- When a claim changes, the writing changes: edit the section, and say in `docs/decisions.md` what
  moved and why.

Style lives in `docs/writing/style.md`. Whoever owns the writing owns that file.
