# Inbox

Drop anything here: a draft, a half idea, a critique, a link dump, a notebook dump. Any format.
No protocol, no template, no permission needed.

This folder exists so that landing a document is never blocked on knowing the rules. When something
here becomes a claim the team is trading on, it gets promoted:

1. Write it up as `docs/theses/<id>.md`.
2. Append one line to `docs/theses/index.jsonl`.
3. `make current` to refresh the view, `make check` to validate.

Promotion is not required. Most of this folder should stay unfinished. That is what it is for.
